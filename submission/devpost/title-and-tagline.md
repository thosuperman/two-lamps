# Project identity

**Project name:** Two Lamps

**Tagline (≤ 60 chars):** Stack blocks so both shadows match. New plaza daily.

**Elevator pitch (one sentence):**
Two lamps light a tiny plaza, each throwing a shadow on its own wall, and every day you get a fresh silhouette to match with as few blocks as you can.

**Short description (for cards and listings, about 200 chars):**
A daily shadow puzzle for Reddit. Tap to stack blocks until both lamplit walls show the target shadow, then chase par. Every day brings a new twist, and your subreddit's results sit on the same post.

**Category / track:** Best Daily Game (Grand Prize). This is an original game, so the Ported category does not apply.
